# energy-and-credit-risk-analysis
This project was completed as part of the JPMorgan Chase & Co. Quantitative Research Virtual Experience Program, focusing on energy price forecasting, storage valuation, and credit risk analytics using Python, machine learning, and statistical modeling techniques.

## Financial Risk and Energy Analytics

This project focuses on energy price forecasting, storage contract valuation, and credit risk analysis using Python, machine learning, statistical modeling, and data visualization techniques.


## Project Overview (Task 1)
## Energy Price Forecasting and Storage Valuation

This project analyzes historical natural gas prices and develops forecasting models to estimate future energy prices. The analysis includes interpolation, regression-based forecasting, and storage contract valuation to support pricing and energy trading decisions.


## Objectives of Task 1

- Analyze historical natural gas price trends
- Forecast future natural gas prices using regression models
- Perform interpolation for historical price estimation
- Develop a storage contract pricing model
- Generate insights for energy pricing and storage decisions

## Datasets for Task 1

- Nat_Gas.csv
- natural_gas_forecast.csv
- storage_contract_results.csv

## Files Included in Task 1

- nat_gas_analyse.py → Natural gas price forecasting analysis
- storage_pricing.py → Storage contract pricing model
- natural_gas_forecast.csv → Forecasted natural gas prices
- storage_contract_results.csv → Storage contract pricing results

## Tools & Libraries for Task 1

- Pandas

- Matplotlib
- Scikit-learn
- SciPy

## Project Overview (Task 2)
## Loan Default Prediction and Risk Modeling

This project focuses on credit risk analysis using customer loan data. Machine learning models were used to predict default probability, calculate expected loss, and segment customers into FICO score rating buckets for risk evaluation.

## Objectives of Task 2

- Predict loan default probability using logistic regression
- Calculate expected financial loss for loans
- Analyze customer credit behavior using FICO scores
- Segment customers into risk rating buckets
- Generate insights for credit risk management

## Datasets for Task 2

- Task_3_and_4_Loan_Data.csv
- processed_loan_data.csv

## Files Included in Task 2

- loan_data.py → Credit default prediction analysis
- fico_bucket.py → FICO score bucketing analysis
- processed_loan_data.csv → Processed loan dataset
